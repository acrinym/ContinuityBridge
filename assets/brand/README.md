# ContinuityBridge brand and release artwork

This directory contains source-controlled public artwork for ContinuityBridge.

## Canonical files

- `continuitybridge-mark.svg` — canonical vector product mark.
- `release-v1.0.0.svg` — truthful 1.0 release card used by README/release documentation.
- `release-v1.0.0.svg` can also be rasterized to a 1280×640 repository social preview when configuring GitHub repository settings.

Do not use AI-provider logos as the ContinuityBridge product mark. ContinuityBridge is provider-independent.

The mark represents two continuity paths crossing through one shared evidence point.

Platform application/browser icons are generated from the same mark and live under `../icons/` and `../../browser-extension/icons/`.

When changing release artwork, keep download formats and security claims aligned with the actual release workflow. In particular, ContinuityBridge 1.0 publishes portable archives and is currently unsigned / not notarized.
